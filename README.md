## 🎯 Overview
**Smart-Threat-Intelligence-Dashboard** is an interactive security operations and threat intelligence platform designed to visualize cyber threats and automate risk evaluation. It aggregates log events, enriches indicators of compromise (IoCs) with threat intelligence feeds, calculates dynamic risk scores, and presents actionable insights in a clean visual interface.

---

## ✨ Key Features
- **Interactive Threat Visualization:** Real-time charts and metrics highlighting attack trends, top malicious IPs, and alert distributions.
- **Automated Risk Scoring:** Evaluates incoming security events and assigns priority scores to help SOC analysts focus on critical threats.
- **Log Aggregation & Analysis:** Parses and correlates security logs from multiple sources into a unified view.
- **Threat Intelligence Enrichment:** Cross-references suspicious IPs and domains against known threat indicators.
